# mzed

mzed は macOS の単一インスタンスの Markdown ビューア。`mzed` コマンドは起動中のアプリに依頼を渡してすぐ戻る。
パスは正規化して渡し（`cd <dir> && pwd -P`）、mzed のウィンドウを今の作業アプリより前に出さない。

## md を見せる

「mzed で開いて」は**ピン**を意味する。ピンは、mzed がどのプロジェクトを表示していてもサイドバー上部に緑丸付きで並び、
読んでいるタブを奪わない。読み手が都合のよいときに開く。mzed が起動していなければ起動する。

| 頼まれ方 | 実行する |
|---|---|
| 「mzed で開いて」「見せて」、または読んでほしい md を書き終えた | `mzed --pin <file>...` |
| 「タブで開いて」「今すぐ表示して」 | `mzed <file>` |
| 「フォルダごと」「ツリーで」 | `mzed <root>` の後に `mzed <file>` |
| フォルダだけを指定された | `mzed <dir>` |

- パスの指定が無ければ、会話の対象になっている md をピンする
- ピンは期限で自然に消える（既定 24 時間）。読む価値のある md はまとめてピンしてよい
- `unexpected argument '--pin'` と返る mzed はピン機能より古い。`mzed <file>` で開き、そのことを一言添える

### フォルダごと開くときのルート

ファイルのパス `f` から決める。

1. `tasks/` の下 → そのタスクのフォルダ: `b="${f%%/tasks/*}"; a="${f#*/tasks/}"; root="$b/tasks/${a%%/*}"`
2. `docs/` の下 → docs フォルダ全体: `root="${f%%/docs/*}/docs"`
3. 「プロジェクトルートで」と言われた → `git -C "${f%/*}" rev-parse --show-toplevel`
4. それ以外 → 親フォルダ: `root="${f%/*}"`

## メモを反映する

mzed では本文を選択してメモを残せ、1 メモ 1 JSON で `~/.config/mzed/notes/` に溜まる。
メモの確認・反映を頼まれたら [references/notes.md](references/notes.md) を読んで従う。
人間が付けたメモは全件反映し、結果を記録して `done/` へ移す。
