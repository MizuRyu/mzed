### ナビゲーション

| ID | 機能 | 優先度 |
|---|---|---|
| N-01 | サイドバー (Obsidian ライク、フォルダ横にファイル件数表示。symlink のディレクトリ / md も実体を追って表示。循環は深さ上限8で抑止。未読ファイルは緑丸表示 → N-06) | ★★★ |
| N-02 | 目次 (ToC) パネル | ★★★ |
| N-03 | マルチタブ（全タブを同じ1行に並べて横スクロール。重ね描きはしないので他のタブに被らない。ホイール（縦ホイールも横に流す）とトラックパッドの横スクロールで送れる。スクロールバーは 4px。タブ切替時はアクティブタブを可視範囲へ寄せる。各タブは 96〜220px でファイル名は省略記号、同名ファイルが複数あるタブには親ディレクトリ名を薄く添える。ホバーでプロジェクト相対パスを表示。新規タブは既定で左端に入る（`tab_insert` で末尾に戻せる。既に開いているタブを開き直したときは位置を動かさない）。最後のタブを Cmd+W で閉じるとそのウィンドウは画面から消える（macOS 標準。アプリは終了せず Cmd+Q で終わる） → [07](07-ipc-and-concurrency.md#ウィンドウの退場最後のタブを閉じたとき), [10](10-settings-and-context-menu.md)） | ★★★ |
| N-04 | ファイル内検索 (Cmd+F) | ★★★ |
| N-05 | 全文検索 | ★★☆ |
| N-06 | 未読マーカー（エージェント等が作成・更新した md を、サイドバーに緑丸+配下フォルダの未読件数、ツールバーに未読件数バッジで表示。バッジをホバーすると未読一覧ポップオーバー（最大20件・mtime 降順・クリックで開く）+「すべて既読にする」。Cmd+P でも未読ファイルを先頭表示+緑丸。ファイルを開く／表示中にライブリロードされると既読化。プロジェクトを初めて開いた時点で既にあるファイルは既読扱い（全部緑にならない）） | ★★☆ |

### ファイル管理

| ID | 機能 | 優先度 |
|---|---|---|
| F-01 | CLI ファイル指定 (`mzed file.md`) | ★★★ |
| F-02 | CLI ディレクトリ指定 (`mzed docs/`) | ★★★ |
| F-03 | ドラッグ & ドロップ（ウィンドウ全体で受付。ドラッグ中はドロップオーバーレイを表示。md → 単体ファイルとしてフォーカス中ペインで開く（プロジェクトは変えない）、ディレクトリ → プロジェクトルート切替、それ以外 → toast で通知） | ★★☆ |
| F-04 | ライブリロード | ★★★ |
| F-05 | セッション永続化（ルート・タブ・プロジェクト別最終ページを保存し次回復元） | ★★☆ |
| F-06 | 右クリックメニュー (Reveal/Open/Copy Path/Rename/Delete) → [10](10-settings-and-context-menu.md) | ★★☆ |
| F-07 | プロジェクトオープン時に最終更新ファイルを自動で開く（config トグル、デフォルト OFF） | ★★☆ |
| F-08 | `mzed serve` — フォルダをブラウザで表示（127.0.0.1 固定、live-reload、画面共有向け） → [12](12-web-serve.md) | ★★☆ |
| F-09 | worktree オーバーレイ — linked worktree 側の docs 更新を main 表示に反映（mtime 最新を表示。ツリー合成・Task View 帰属・全文検索も対象） → [05](05-zed-integration.md) | ★★☆ |
| F-10 | worktree を開いたら親リポジトリに付け替える（`worktree_switch`: main / skip / follow、既定 main。プロジェクトの新規オープン経路に適用） → [05](05-zed-integration.md) | ★★☆ |
